# Smart Campus Energy Analyzer & Predictor

## Project Overview
This project uses Simple Linear Regression to predict electricity consumption based on computer lab operating hours.

## Objectives
- Analyze electricity consumption data.
- Visualize the relationship between operating hours and electricity consumption.
- Build a Linear Regression model.
- Evaluate model performance.
- Predict electricity consumption for new inputs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Algorithm
Simple Linear Regression

## Dataset
The project uses a sample synthetic dataset containing:
- Operating Hours
- Electricity Consumption (kWh)

**Note:** The dataset contains illustrative values and is not actual college electricity meter data.

## Project Features
- Data exploration and analysis
- Data visualization
- Train-test splitting
- Linear Regression model training
- Model prediction
- Performance evaluation using MAE, MSE, RMSE and R²
- Residual analysis
- Interactive electricity consumption prediction

## How to Run
1. Open the project notebook.
2. Click Open in Colab.
3. Run all cells.
4. Enter lab operating hours to get a prediction.

## Learning Outcomes
This project provides practical experience in data analysis, visualization, supervised machine learning and model evaluation.
